### 📦 Open Source

#### 🛠️ CLI & Dev Tools

- 💻 [**dotfiles**](https://github.com/OzzyCzech/dotfiles) – Collection of my personal macOS dotfiles & setup.
- 🚀 [**ftpsync**](https://github.com/OzzyCzech/ftpsync) – Fast hash-based FTP/FTPS deploy tool in Rust — uploads only changed files, no SSH needed.
- 🌍 [**potrans**](https://github.com/OzzyCzech/potrans) – CLI tool to translate Gettext (.po) files via Google Translate or DeepL.
- 🔄 [**mock-to-openapi**](https://github.com/OzzyCzech/mock-to-openapi) – Convert JSON mock objects to OpenAPI schemas.
- 🤖 [**claude-code-statusline**](https://github.com/OzzyCzech/claude-code-statusline) – Dense, width-aware status line for Claude Code — model, context, prompt cache, usage limits, git state and MR/PR pipeline.
- 🔒 [**SSLko**](https://github.com/OzzyCzech/sslko/) – Parse SSL/TLS certificate details from a remote host.
- 👾 [**Diggy**](https://github.com/OzzyCzech/diggy/) – Flexible, multi-backend JavaScript DNS resolver.
- 📄 [**mreader**](https://github.com/OzzyCzech/mreader) – Extract clean Markdown from any URL.
- 🔑 [**pux-to-html**](https://github.com/OzzyCzech/pux-to-html) – Convert 1Password (1PUX) exports to plain HTML.

#### 🐘 PHP Libraries

- 📅 [**icalparser**](https://github.com/OzzyCzech/icalparser) – Simple iCal parser for PHP.
- ✨ [**latte-lucide-icons**](https://github.com/OzzyCzech/latte-lucide-icons) – Lucide icons in Latte templates via the `{lucide}` tag.
- 🧩 [**fromArray**](https://github.com/OzzyCzech/fromArray) – Lightweight PHP trait for hydrating objects from associative arrays.

#### 🗓️ Calendar & Dates

- 🏖️ [**Holidays CS**](https://github.com/OzzyCzech/holidays-cs) – Public holidays and significant days in the Czech Republic.
- 🎉 [**Namedays CS**](https://github.com/OzzyCzech/namedays-cs) – A library for handling Czech namedays data.
- 📆 [**International Days CS**](https://github.com/OzzyCzech/international-days-cs) – A comprehensive library for international days in Czech.
- 🐣 [**Easter Date**](https://github.com/OzzyCzech/easter-date) – A handy library to calculate the date of Easter.

#### 🎨 Web & UI Components

- ⌨️ [**Cmd Dialog**](https://github.com/OzzyCzech/cmd-dialog/) – Command dialog and keyboard shortcuts palette for web apps.
- 🍞 [**Toastik**](https://github.com/OzzyCzech/toastik) – Lightweight, dependency-free toast notification component for Vue 3.
- 🔎 [**Selectix**](https://github.com/OzzyCzech/selectix) – Searchable select component for Vue 3 with Tailwind CSS.
- 🎨 [**Wticons**](https://github.com/OzzyCzech/wticons) – Website technology icons bundle for Astro and React.
- 🐞 [**Tailwind Debug**](https://github.com/OzzyCzech/tailwind-debug) – Tailwind plugin that adds a red dashed outline to debug any element.
