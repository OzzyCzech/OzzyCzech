### 📦 Open Source

#### 🛠️ CLI & Dev Tools

- 💻 [**dotfiles**](https://github.com/OzzyCzech/dotfiles) – Collection of my personal macOS dotfiles & setup.
- 🚀 [**ftpsync**](https://github.com/OzzyCzech/ftpsync) – Fast hash-based FTP/FTPS deploy tool in Rust — uploads only changed files, no SSH needed.
- 🌍 [**potrans**](https://github.com/OzzyCzech/potrans) – CLI tool to translate Gettext (.po) files via Google Translate or DeepL.
- 🔄 [**mock-to-openapi**](https://github.com/OzzyCzech/mock-to-openapi) – Convert JSON mock objects to OpenAPI schemas.
- 🔒 [**SSLko**](https://github.com/OzzyCzech/sslko/) – Parse SSL/TLS certificate details from a remote host.
- 👾 [**Diggy**](https://github.com/OzzyCzech/diggy/) – Flexible, multi-backend JavaScript DNS resolver.
- 📄 [**mreader**](https://github.com/OzzyCzech/mreader) – Extract clean Markdown from any URL.

- 🎉 [**Namedays CS**](https://github.com/OzzyCzech/namedays-cs) – A library for handling Czech namedays data.
